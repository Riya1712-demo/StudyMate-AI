
# StudyMate AI 🎓

An AI-powered personal study assistant built using
Python, Streamlit, Ollama and Llama 3.2.

## Features

- AI Academic Chatbot
- Notes Summarizer
- Quiz Generator
- Concept Explainer

## Technologies

- Python
- Streamlit
- Ollama
- Llama 3.2 (3B)

## How to Run

1. Install Ollama.
2. Download the model:

   ollama pull llama3.2:3b

3. Install dependencies:

   pip install -r requirements.txt

4. Start the application:

   streamlit run app.py

## Project Objective

To help students learn more effectively using
artificial intelligence.
